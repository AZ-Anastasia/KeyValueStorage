# Key Value Storage TTL MVP

Приложение для централизованного хранения конфигураций и прочих файлов. Позволяет изолированно сохранять и считывать данные формата `Key -> Value` через HTTP-интерфейс.

Технологический стек
- `FastAPI` — веб-фреймворк, который отвечает за обработку запросов и сам рисует красивый визуальный интерфейс (Swagger) в браузере.
- `Pydantic` — встроенный контролер, который проверяет, что пользователь ввел правильный текст, а не пустые строки или ошибки.
- `SQLAlchemy` — умная прослойка (`ORM`), которая позволяет коду общаться с БД на языке понятных объектов и классов, без написания сложных SQL-запросов вручную.
- `PostgreSQL 16` — БД, где физически хранятся все записи.
- `Docker & Docker Compose` — инструмент, который автоматически запускает и настраивает БД PostgreSQL в изолированном контейнере одной командой.
