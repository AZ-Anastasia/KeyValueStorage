# venv

***venv*** - для создания виртуального окружения для проекта (например, если в старом проекте требуется версия 1.0..., а в новом - 2.0..., то нужен venv для разграничения, иначе перетрет в Global версию, скачав более новую. К тому же, это нужно, чтобы в Global не хранились все подряд пакеты).

Папки и файлы внутри:
- `bin` - локальная копия интерпретатора `python`, утилита установки пакетов `pip` и скрипты активации этой "песочницы" (`activate`). При запуске происходит обращение к папке `bin`, а не к глобальному `python`.
- `include` - C/C++ компиляторы.
- `lib` и `lib64` - аналог `Nuget`.
- `pyvenv.cfg` - главный конфигурационный файл.

***Отправлять в Git нельзя.***
